# 把你的 PPT 模板放进这个目录

本技能出 PPT 需要一个**底层版式模板**。分发包里不带模板（模板含原作者的品牌页），
所以**第一次使用前，你要往这里放一个自己的 pptx**。

## 放一个，别放多个

```
assets/templates/你的模板.pptx      ← 只放这一个
```

放好后，命令行可以省略模板参数，脚本会自动找到它：

```bash
python scripts/build_ppt_slides.py 我的学员.json
```

想临时换另一份模板，就把路径写在第 2 个参数上：

```bash
python scripts/build_ppt_slides.py 我的学员.json "另一个模板.pptx"
```

> 目录里放了多个 `.pptx` 时，脚本只会取**排序后的第一个**并打印提示。
> 别把临时打开的 `~$xxx.pptx` 残留文件留在里面（脚本已自动过滤）。

## 模板要满足什么条件

脚本对模板**没有硬性结构要求**——任何 16:9 或 4:3 的 pptx 都能跑：

- **能匹配到页面**：脚本按页标题关键词找「学员信息」「院校定档」两页；
  找不到就自动克隆一页同版式页面再放表。所以模板里有没有这两页都能出结果。
- **第 1 页是封面**：默认会把封面上的院校/专业换成本次学员信息。
  不想要这个动作就加 `--no-cover`。
- **版心**：表格按「左避导航条、下留 0.56in」的标准版心精算，
  你的模板左侧有导航条也没关系。

## 想要 26 页那种完整版式怎么办

原模板是 16:9 / 26 页 / 左侧四段导航 + 右侧内容区，第 2 页放「学员信息」、
第 3 页放「院校定档」，其余页是政策、规划、服务流程、学员反馈等讲稿页。
**你需要自己做一份**（或用你团队现成的规划 PPT 改造）：

1. 复制一份你常用的保研规划 PPT；
2. 把「学员信息」「院校定档」两页里的旧表格/截图**删掉，只留页标题**；
3. 另存为 `.pptx` 放进本目录。

脚本会自动清掉没投表格的空内容页（不想删加 `--keep-empty-pages`）。

## 先空跑一次验证

```bash
python scripts/build_ppt_slides.py 我的学员.json --dry-run
```

只打印字号、表高、列宽不写文件，确认没溢出再真跑。
