# 保研规划 PPT Skill —— 快速上手（同事分发版）

一句话：**给学员信息 → 出 PPT（两张原生表格规划表）**；**给政策文件 → 出一份家长学生解读 HTML**。

> 2026-09-17 起由"四表"改为"三表"；2026-09-19 二次定版 PPT 只出两张表（模板 26 页）；三次定版主线任务表全面下线。
> **2026-09-19 四次定版（当前）**：**Excel 交付全面下线——不再生成 xlsx，交付物只有 PPT + 数据源 JSON**。`generate_tables.py` 保留仅作回溯。
> **2026-09-21 五次定版（当前）：PPT 直接输出到桌面。** 不写输出文件名时自动命名为 `保研规划_<院校>.pptx` 并落到桌面，写完就在桌面上，不用再去找。

---

## 1. 安装（只做一次）

```bash
pip install python-pptx
pip install pypdf          # 形态 C（政策解读 HTML）抽 PDF 用
```

然后把整个 `baoyan-planner-tables` 文件夹放到你的 skills 目录：

- Windows：`C:\Users\<你的用户名>\.workbuddy\skills\baoyan-planner-tables`
- macOS / Linux：`~/.workbuddy/skills/baoyan-planner-tables`

放好后重启一次 WorkBuddy 即可识别。

---

## 2. 怎么触发

在 WorkBuddy 里随便哪种说法都能唤起本技能，例如：

- **出 PPT**：`用保研四表技能，帮 26 级大连海事大学电子信息的新学员出一份 PPT`
- **只要表格**：`保研三表，学员：XX大学XX专业，大一`（默认也走 PPT）
- **出政策解读 HTML**：`根据这个政策，给我出一份面向家长和学生的分析表，html 格式`

技能识别到"保研规划 / 保研三表 / 保研四表 / 冲稳保定档 / 学员信息表 / 出 PPT / 【你的称呼】模板"这些词就会自动加载。
给一份**政策文件**（推免/保研规定 PDF）而非学员背景时，自动走形态 C（政策解读 HTML）。

---

## 3. 两种交付形态

### PPT（默认且唯一）

两张表（学员信息 / 院校定档）以 **PowerPoint 原生表格**写进 PPT，不是截图——可以继续改字、换色、调合并。**主线任务表不再进 PPT**（2026-09-19 定版）。

- **你把 PPT 给我** → 替换该 PPT 里对应的两页
- **你没给 PPT** → 自动套用模板目录里的版式模板

> ⚠️ **本分发包不含模板 PPT**（原模板带作者品牌页，已剔除）。
> **首次使用前先放一个你自己的 pptx 到** `assets/templates/`，详见该目录下的《放你的模板到这里.md》。
> 放好后可以省略模板参数，脚本自动发现；没放会直接报错退出。

模板位置：

```
baoyan-planner-tables/assets/templates/你的模板.pptx   ← 需要你自己放
```

参考版式（原作者用的）：16:9 / 26 页 / 左侧四段导航 + 右侧内容区，第 2 页「学员信息」、第 3 页「院校定档」。
你不必照抄——**任何 pptx 都能跑**，脚本按页标题关键词找页，找不到就自动克隆同版式页面。

**三个自动动作**，每次出 PPT 都会做，不用手动：

1. **第 1 页封面自动同步学员信息** —— 院校名、专业名换成这次的学员，不会沿用上一份。
2. **院校层次自检** —— 生成前先检查定档院校是否都是 985/211/双一流（中国科学院大学及中科院研究所为特例），每档是否够 4 所，软科排名梯度是否与档位一致。**不合格会中止并打印明细**，改好数据再跑。
3. **删掉没用上的空内容页** —— 模板里"只剩页标题、内容区全空"的页，如果这次没投表格，输出时会自动移除。当前 2.0 模板正好 2 个内容页（学员信息 / 院校定档分析），全被用上，**输出就是 26 页**（2026-09-19 已删掉原第 4 页主线任务分析页）；用旧版或其他 PPT 时可能会少一两页，属正常。不想删就加 `--keep-empty-pages`。

### 形态 C：政策解读 HTML（给政策文件，不给学员）

**输入是院校的推免/保研政策文件（PDF 或网页原文），输出一份面向家长和学生的解读分析表**（单文件 HTML，深红主题，可直接打印 / 转 PDF）。

两行命令：

```bash
# 第 0 步：把政策 PDF 抽成纯文本（通读后再动笔，别凭印象写分值）
python scripts/extract_policy_text.py "XX大学保研政策.pdf" --out policy_text.txt

# 生成 HTML
python scripts/build_policy_html.py policy_data_XX大学.json "XX大学推免政策_家长学生解读分析表.html"
```

固定 11 个模块：一页速览数字卡 / 资格门槛 / 一票否决 / 综合成绩算法 / 奖励分全景对照表 / 行动路线图 / 名额分配 / 工作流程 / 红线与风险清单 / 家长 FAQ / 待学院确认清单。
数据文件照 `assets/policy_sample_data.json`（天津工业大学真实例子）改即可，**不用碰脚本**。缺模块脚本会告警。

**形态 C 的三条铁律：**

1. **原文与解读分家** —— "分值 / 否决情形 / 流程"严格照抄原文；"难度 / 性价比 / 行动路线图"属分析意见，页脚必须声明非官方口径（脚本缺省页脚已带）。
2. **不可补救的条款一定要单独点出来**（典型："首次修读不合格"——家长普遍误以为重修过了就行）。
3. **凡是政策写"由各学院自行制定"的，一律进「待确认清单」**，不要替学院拍板。

## 4. 底层命令（想自己跑时用）

```bash
# PPT —— 用模板目录里的模板（主流程）。模板参数可省略，脚本自动发现；
#         不写输出名也可以，脚本会自己命名并放到桌面
python scripts/build_ppt_slides.py 我的学员.json
python scripts/build_ppt_slides.py 我的学员.json assets/templates/你的模板.pptx 保研规划_姓名.pptx

# PPT —— 用我自己的 PPT
python scripts/build_ppt_slides.py 我的学员.json "我的PPT.pptx" "输出.pptx"

# 政策解读 HTML —— 先抽 PDF 文本，再生成
python scripts/extract_policy_text.py "XX大学保研政策.pdf" --out policy_text.txt
python scripts/build_policy_html.py policy_data_XX大学.json "XX大学推免政策_家长学生解读分析表.html"

# 先预检不写文件（推荐！看字号和是否溢出）
python scripts/build_ppt_slides.py 我的学员.json 模板.pptx out.pptx --dry-run
```

### 常用参数

| 参数 | 用途 |
|---|---|
| `--dry-run` | 只打印每张表的字号、表高、列宽，不写文件（末尾会打印"将输出到"的绝对路径） |
| `--dir <路径>` | 强制指定输出目录（优先级最高） |
| `--no-desktop` | 关掉"默认放桌面"，退回写到当前工作目录 |
| `--slides 2,3` | 手动指定两张表的页码（顺序：学员信息/院校定档） |
| `--mode append` | 不替换，在末尾追加新页 |
| `--keep-empty-pages` | 保留没投表格的空内容页 |
| `--max-font 11` | 内容装不下时下调字号上限 |
| `--theme auto` | 表格配色跟随 PPT 主色调（默认深红主题） |
| `--no-cover` | 不改写第 1 页封面 |
| `--no-tier-check` | 跳过院校层次自检 |
| `--force` | 自检不通过也强行生成 |
| `--ppt-trim` | 文案超限时自动截断（默认只告警不截断） |

## 5. 数据文件长什么样

技能会自动生成 `student_data_xxx.json`，改这个文件重跑即可，**不用改脚本**。

```json
{
  "meta":  { "school": "西北农林科技大学", "major": "环境科学（中外合作办学）" },
  "cover": { "school": "西北农林科技大学", "major": "环境科学（中外合作办学）" },

  "student_info": {
    "headline": "环境科学（中外合作办学），四级538，大二在读，38/82",
    "rows": [ { "label": "基本情况", "content": "..." } ]        // 固定 4 行：基本情况/保研数据/保研方向/注意事项（「院校定位」行已删）
  },

  "school_tiers": [
    { "tier": "冲刺档", "school": "南京大学（环境学院）", "level": "985", "rank": 6,
      "direction": "...", "fit": "..." }     // requirement 可选，写了也不渲染（Excel 已下线）
  ],

  "main_timeline": [       // 已下线：可整体省略，保留仅为兼容旧数据
    { "time": "大二上\n9月-1月", "score": "...", "english": "...",
      "competition": "...", "research": "...", "other": "..." }
  ],

  "ppt_tables": {          // 可选：只写与上面不同的字段（PPT 短文案覆盖块）
    "school_tiers":  [ { "school": "哈工大（环境学院）" } ]
  }
}
```

- `level` 取值 `"985"` / `"211"` / `"双一流"` / `"中科院"` / `"海外"`；`rank` 填**软科中国大学排名**位次（自检靠它校验档位梯度）。
- 海外兜底行（中外合作 4+1、双学位直升）写 `"overseas": true`，且必须放**保底档最后一行**。
- 完整样例见 `assets/sample_data.json`，直接复制改成自己的学员即可。

**PPT 版文案的长度标准**（单位＝单格总字数，超了只告警）：

| 表 | 单格上限 |
|---|---|
| 学员信息表（4 行） | 表头摘要 **40** / 内容 **160** |
| 冲稳保定档表（4 列） | 适配院校 **12** / 方向 **20** / 优势 **24**（录取条件列已随 Excel 下线，不渲染） |
| 主线任务表 | **已全面下线**（2026-09-19，不生成） |

要点：**用 `\n` 显式断行**；写"动宾短语"，不要写完整句子。生成时脚本会体检文案，出现 `⚠ 超限` 就回去删字，别靠压字号掩盖。

> 定档表最吃空间：**适配院校压到 ≤12 字**（长校名换简称，如 `哈尔滨工业大学（环境学院）` → `哈工大（环境学院）`）。

## 6. 铁律（技能会自动遵守，你也要知道）

1. **定档院校必须是 985 / 211 / 双一流，或中国科学院大学及中科院各研究所**；双非、四非一律不进任何档位（含学员本校），保底档最低 211。唯一例外是**海外兜底行**（学员确有中外合作/双学位项目），且只能放保底档末行。
2. **每档 4 所**（冲刺/稳妥/保底各 4，共 12 行），首列「梯度」纵向合并。
3. 定档按**实际录取难度**排序（学科评估 + 区位 + 招生规模 + 软科位次），`rank` 用于校验梯度；写数据前先联网核实当年软科排名。
4. **主线任务表已下线**（2026-09-19）：不再生成，JSON 里的 `main_timeline` 字段保留兼容但不渲染。
5. **Excel 已下线**（2026-09-19 四次定版）：不跑 `generate_tables.py`、不交 xlsx；用户明确点名"就要 Excel"才恢复。
6. 学员信息表固定 4 行（基本情况 / 保研数据 / 保研方向 / 注意事项），**不写「院校定位」行**——三档院校以表 2 为准。
7. 长文本单元格"横向靠左 + 纵向居中"，梯度列居中，表头居中。
8. **PPT 封面每回自动换成本次学员的院校与专业**，不沿用上一份。
9. 动笔前先联网核实学员院校的保研率、推免硬条件、招生培养变动。
10. 学员信息给得简（如"26 级"= 2026 级）时，缺省项自行推断并标注，不追问。
11. **字数只减不增**——每格写短语不写长句。
12. **形态 C（政策解读 HTML）**：分值、名次、截止日期一律照抄政策原文，不推断；政策里"由各学院自行制定"的部分全部落进「待确认清单」；页脚免责声明不删。
