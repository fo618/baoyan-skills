# 阶段关卡与成交链

> 从「已成交」客户的真实对话里逆向出来的流程。
> 📊 **本文件里的所有百分比与倍数（49% / 22% / 1.7× / 28 天中位数…）来自原作者的样本，只作量级参考**——
> 你跑完 `scripts/analysis/deal_review.py` 后应**用自己的数据重算并覆盖**。
> **核心原则：没有证据，不算推进。** 销售最容易犯的错是「自我感觉良好」——以为聊得热就是意向高。
> 所以每一步都设了**退出标准（关卡）**：没拿到那个证据，就还停在这一步。

---

## 一、六步成交链（附带关卡）

| # | 阶段 | 你要做的关键动作 | **退出标准（拿到这个才算过关）** | 常见卡点 |
| --- | --- | --- | --- | --- |
| S1 | **破冰建档** | 规划师自我介绍 + 信息采集表（哪年入学/院校/专业/排名/英语/竞赛/诉求） | 客户**回填了采集表**（至少给了院校 + 年级） | 只问「在吗」不填表 → 用「填了才能给针对性规划」换 |
| S2 | **诊断定档** | 发学校保研政策 + 84 项竞赛名录；把焦虑具体化（科研占比 50%，论文竞赛很关键） | 客户**确认了目标院校 / 时间线**，或同意约腾讯会议 | 客户只回「好的」→ 用「约会议整体梳理」逼一个具体时间 |
| S3 | **方案报价** | 先给成果（项目卡：形式/班型/课时/导师/成果）再给价格；给两档（分期 60%+尾款 / 全款优惠） | 客户**知道了价格并开始讨论**（问优惠/问分期/问包含什么） | 只发方案不报数 → 价格必须明说，含糊等于没推进 |
| S4 | **破异议** | 逐条拆：价格→领导权限；效果→退费保障；对比→品牌确定性；拖延→孩子的代价 | 客户**不再重复同一异议**，转向问细节（师资/课时/开课时间） | 客户反复问价 → 说明价值没讲够，退回 S3 补成果 |
| S5 | **逼单** | 名额稀缺 + 时间节点（月底/期末/开课）+ 领导权限 三件套 | 客户**口头承诺**（「那我看一下合同」「明天给你答复」「先交定金」） | 客户说「跟家里商量」→ 必须**约下次跟进的具体时间**，别放走 |
| S6 | **签约交付** | 甲方信息表 → e签宝 → 对公账户 → 收定金/全款 → 当晚建服务群 | **收到款 / 客户回填甲方信息** | 只发了链接没跟 → 24h 内必须闭环，否则热度归零 |

**数据支撑的三个倍数差（这就是发力点）**

| 动作 | 成交客户做过 | 未成交客户做过 | 差 |
| --- | --- | --- | --- |
| 发过甲方信息表 | 13+ 会话（跨会话复用） | — | — |
| 发过 e签宝 | 49% | 29% | 1.7× |
| 发过对公收款账户 | 22% | 6% | 3.7× |
| 平均语音条数 | 11.7 | 5.5 | 2.1× |

> **一句话**：成交客户一定会走完「甲方信息表 → e签宝 → 对公账户 → 收款」这条链。**你不敢开口要合同，单子就停在门口。**

## 二、卡关诊断表（客户停住了，先查他卡在哪一关）

| 看到的症状 | 真实卡点 | 该做什么 |
| --- | --- | --- |
| 聊得很好，但一报价就沉默 | S3 价值没铺够 | 退回补成果：项目卡 + 具体导师 + 往期案例，**别降价** |
| 反复问「能不能便宜点」 | S4 价格异议 | 走「守价 → 帮您申请 → 给争取来的优惠」三步，同时给非价格台阶（加送课时） |
| 「我再考虑考虑 / 跟家里商量」 | S4→S5 之间 | 换算成孩子的代价（期末/绩点/名额），并**约定下次沟通的具体时间** |
| 「你们太贵了，XX 家便宜」 | S4 对比异议 | 不比价格比确定性：品牌年限 + 服务学员数 + 行业奖项 |
| 「等孩子放假 / 等期末考完再说」 | S4 拖延异议 | 挂真实学业节点：正好期末我们老师能介入提绩点，**晚了就错过窗口** |
| 方案发了、账户给了，就是不打款 | S6 收口松了 | 当天闭环：电话 + 合同链接 + 「今天签，晚上就建服务群」 |
| 静默超过节奏阈值（见 05 文档） | 关系降温 | 别追问「在吗」——投喂价值（政策更新/竞赛截止/同校案例）再收口 |

## 三、成交周期铁律（来自真实数据）

- **成交周期中位数 28 天**；≤7 天的闪电单只占 **24%**，**超过 30 天的长线单占 48%**。
- 结论：**近一半的单子是「跟出来的」**。客户当场没成，不等于没戏。
- 所以：**建立长线培育池**，每周固定投喂一次价值，卡「月底 / 期末 / 开课 / 报名截止」节点收口。
- 反面教训：静默 → 断联 → 客户被别家签走。**没有「聊完就放着」这一说。**

## 四、自检三问（每次聊完问自己）

1. **比上次多拿到了什么证据？**（回填了表？确认了目标？答应了几点沟通？）
2. **下一步的具体动作和具体时间是什么？**（不能是「继续保持沟通」）
3. **这次有没有开口要合同/要信息？**（没开口 = 这一轮白聊）
